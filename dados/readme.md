# Lanzador de Dados – El Castillo Vagabundo

Este proyecto es un **lanzador de dados virtuales** inspirado en el universo de **El Castillo Vagabundo**, diseñado para jugadores de rol y juegos de mesa.
Permite lanzar diferentes tipos de dados (d4, d6, d8, d10, d12, d20, d100) y visualizar el resultado con una interfaz personalizada con la identidad visual del Castillo.

## 📂 Estructura del Proyecto

```
dados/
│── index.html       # Página principal
│── style.css        # Estilos de la aplicación
│── script.js        # Lógica del lanzador de dados
│── assets/          # Carpeta para imágenes, íconos y logo
```

## ⚙️ Instalación y Uso

1. Clona este repositorio en tu máquina local:

```bash
git clone https://github.com/a81Biz/dados.git
```

2. Ingresa a la carpeta del proyecto:

```bash
cd dados
```

3. Abre el archivo `index.html` en tu navegador preferido (Chrome, Firefox, Edge, etc.):

```bash
# En Linux/macOS
open index.html  

# En Windows (PowerShell)
start index.html  
```

✅ ¡Listo! Ya puedes comenzar a lanzar tus dados.

## 🎨 Tecnologías Utilizadas

* **HTML5** – Estructura del proyecto
* **CSS3** – Estilos y maquetación con la paleta oficial del Castillo Vagabundo
* **JavaScript (ES6)** – Lógica del lanzador de dados
